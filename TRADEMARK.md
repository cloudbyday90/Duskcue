# Duskcue Trademark Policy

## Purpose

This document defines the trademark usage policy for the Duskcue project. The Duskcue name and logo are intended to be registered trademarks of the project. This policy exists to protect users from confusion while allowing the community to reference the project freely.

This policy is separate from the [LICENSE](LICENSE) (AGPL v3). AGPL v3 Section 7(e) allows preservation of legal notices but does not grant trademark rights.

## Trademark Ownership

"Duskcue" and the Duskcue logo are trademarks of the Duskcue project. All rights reserved.

This follows the same model used by Nextcloud, Grafana, and other AGPL-licensed projects: the code is open source, but the name and brand identity are protected to prevent marketplace confusion.

## Permitted Uses

The following uses do not require written permission:

### Referential Use

- Saying your product or service works with Duskcue ("compatible with Duskcue")
- Linking to the official Duskcue repository or website
- Using the word "Duskcue" in documentation, blog posts, or tutorials when referring to the project
- Using the name in package managers, container registries, or build configurations (e.g., `docker pull duskcue/duskcue`)

### Community Use

- Local user group names (e.g., "Duskcue Users of Berlin")
- Community-maintained tools, plugins, or themes that clearly state they are unofficial ("unofficial Duskcue theme")
- Educational content, conference talks, or meetups about Duskcue

### Fork and Contribution Use

- Forked repositories on GitHub/GitLab (the AGPL v3 guarantees this right)
- Contributing code upstream (you retain copyright to your contributions, not trademark rights)
- Internal deployments within your organization

## Uses Requiring Permission

The following require written permission from the Duskcue project:

### Commercial Use of the Name or Logo

- Using "Duskcue" in a company name, product name, or service name
- Selling hosted Duskcue instances under the Duskcue name
- Using the Duskcue logo on merchandise, swag, or commercial packaging
- Offering paid support services branded as "Duskcue Support" or similar

### Modified Versions

- Distributing modified versions of Duskcue under the "Duskcue" name (this would confuse users into thinking it is the official version)
- Using the Duskcue name or logo for a fork that is not clearly distinguished from the official project

The AGPL v3 grants you the right to modify and distribute the code. This policy does not restrict that right. However, modified versions distributed to others must:

1. Use a different name (not "Duskcue")
2. Clearly state they are a modified version, not the official distribution
3. Not use the Duskcue logo as the primary branding

### Domain Names

- Registering domain names containing "duskcue" for commercial purposes
- Domain names for community or non-commercial purposes are generally permitted but should not impersonate the official project

## Guidelines for Using the Name

| Context | Written as | Example |
|---|---|---|
| Product name (prose) | Duskcue | "Duskcue is a self-hosted media server." |
| Binary, CLI, Docker image | duskcue | `duskcue --version`, `docker run duskcue` |
| Environment variables | DUSKCUE_ | `DUSKCUE_DATABASE_URL` |
| Rust module paths | duskcue | `use duskcue::router;` |
| GitHub organization | duskcue | `github.com/duskcue` |

## Logo Usage

The Duskcue logo may be used without permission in the following contexts:

- Linking to the official Duskcue website or repository
- In blog posts, articles, or presentations about Duskcue
- In a list of compatible software or integrations

The logo must not be:

- Modified, distorted, or used as part of a larger logo without permission
- Used in a way that implies endorsement by the Duskcue project
- Used as the primary brand for a modified version or competing product

## Enforcement

The Duskcue project will enforce this policy to prevent:

- User confusion about what is and is not the official project
- Bad actors using the Duskcue name to distribute malware or compromised software
- Commercial entities misrepresenting their relationship with the project

Enforcement will be proportional:

1. First contact: friendly request to comply
2. Continued misuse: formal cease-and-desist
3. Bad-faith or harmful misuse: legal action

## Contact

For trademark permission requests, contact the Duskcue project maintainers through the official repository.

## Changes

This policy may be updated from time to time. Substantive changes will be communicated through the project's official channels.
