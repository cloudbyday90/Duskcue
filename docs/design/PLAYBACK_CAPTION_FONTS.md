# Runtime caption fonts

The actual Alpine runtime image could encode successfully while burning no visible SRT text. Its system font directories were absent, and libass could not resolve the default Arial font through its fontconfig provider. The selected embedded subtitle was correct: a diagnostic supplying Inter and selecting that family rendered the expected selected text. Font files and a usable provider are therefore part of the runtime streaming contract, alongside FFmpeg and libass.

The production Dockerfile installs a focused set: `font-noto`, `font-noto-arabic`, `font-noto-hebrew`, `font-noto-devanagari`, `font-noto-thai` and `font-noto-cjk`. The base package covers Latin, Cyrillic and Greek; the additional packages supply the named script families. The tested `docker/fonts/60-duskcue-sans-fallback.conf` gives Arial and generic sans-serif a preferred order of actual text families. This prevents an available mathematical face from winning Arabic fallback. The rule uses Fontconfig's documented alias/prefer ordering and retains the matched binding; it applies to the default Arial/generic sans requests while leaving other explicit family lookups and FFmpeg caption styles unchanged. Arial aliases may change font metrics; authored font availability and arbitrary ASS layout are separate content qualification. Sources reviewed October 7, 2026: [Fontconfig matching and alias reference](https://fontconfig.pages.freedesktop.org/fontconfig/fontconfig-user.html), [Alpine Noto family index](https://pkgs.alpinelinux.org/package/v3.24/community/loongarch64/font-noto), [Alpine CJK package](https://pkgs.alpinelinux.org/package/v3.24/community/x86_64/font-noto-cjk).

The broad `font-noto-all` candidate pulled 114 family/variant dependencies, contained 2,175 font files and added 853,885,281 bytes (814 MiB) to the existing image. It passed a coarse changed-pixel condition, but visual review found Arabic reduced to tiny marks because Noto Sans Math won fallback. That candidate is not qualified for release. The focused candidate contains 389 font files and adds 267,377,618 bytes (255 MiB), about 69% less added image size. Both values include the actual installed dependency/cache/filesystem layer; direct package-size estimates are not substituted for the measured image difference. Other scripts may require additional deployment fonts or media-provided font attachments. No complete Unicode or language conformance is claimed.

The existing selected subtitle ordinal, metadata and streaming authentication remain authoritative. The repair changes runtime dependencies, not track selection, DTOs or parental controls. Production filters use their default font/provider; no hardcoded Inter family, test-only font mount or forced caption style is introduced. FFmpeg documents additional font directories and explicit style overrides separately from its provider behavior. Its libass shaping support remains responsible for complex-script layout. Source: [FFmpeg subtitles and ASS filters](https://ffmpeg.org/ffmpeg-filters.html).
