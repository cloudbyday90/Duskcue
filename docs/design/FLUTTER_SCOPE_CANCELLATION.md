## Existing confirmed behavior

- A profile-only transition detaches output and may retain one cleanup-only record for the old viewer, because the same account/session can still request its cleanup. That record cannot deliver media or authorize a new viewer.
- Account, origin/server, session or credential transitions detach output and clear local recovery state. Cleanup of server resources remains server-owned; a new identity cannot borrow the old identity's cleanup authority.
- Scope changes, disposal, observation deadlines and cancelled reads never prove a server mutation did not happen. Do not replay Start, reconfiguration, renewal, Stop or withdrawal automatically. Exact IDs support explicit reconciliation under current authority.
- Background/lease uncertainty still requires current status and explicit Play. Position checkpoints and status reads do not renew a lease. Preserve independent renewal while its owner is current and Dart can run.
- A native/storage/network observation ending does not erase its unfinished resource ownership. Retain the existing finite admission, completion, quarantine and cleanup behavior. A late result cannot publish into another viewer, output or authenticated context.

These rules were accepted in the original migration and subsequent observer reviews. This increment qualifies and repairs their implementation boundaries.

## Official research and application

URLs were discovered through connected MCP search and their official pages retrieved on October 31. Public documentation guides design; inspected locked code governs version-specific behavior. The lock retains Flutter 3.47.8/Dart 3.13.7, Dio 5.10.0, flutter_secure_storage 10.3.4 and video_player 2.11.1. No dependency change is recommended.

- [Dart Future.timeout](https://api.flutter.dev/flutter/dart-async/Future/timeout.html) stops observation while the original future can still complete. Bind both observed result and retained completion to the exact originating work; do not free capacity from the observer's timeout alone.
- [StreamSubscription.cancel](https://api.dart.dev/dart-async/StreamSubscription/cancel.html) returns a cleanup future. Await owned subscription cleanup where release depends on it. An API cancellation request alone is not a physical socket-close acknowledgement.
- [Dio CancelToken](https://pub.dev/documentation/dio/latest/dio/CancelToken-class.html) cancels all requests sharing that token. Use per-operation cancellation for a single observer; reserve whole-transport cancellation for its existing scope/disposal boundary. Retain the SDK operation's completion and independently observe socket closure in qualification; do not infer kernel completion solely from a cancellation signal.
- [Flutter lifecycle states](https://api.flutter.dev/flutter/dart-ui/AppLifecycleState.html) can be skipped when an app is terminated. [Android activity guidance](https://developer.android.com/guide/components/activities/activity-lifecycle.html) describes releasing resources as activity state changes. Keep server leases, durable receipts and cold-restart reconciliation authoritative; lifecycle callbacks cannot promise a final checkpoint or Stop.
- [Flutter integration testing](https://docs.flutter.dev/cookbook/testing/integration/introduction) distinguishes whole-app/device tests from units and notes that integration_test cannot itself operate native platform UI. Reuse the isolated emulator and exact owned ADB actions; do not add a test framework just to exercise existing provider/channel seams.
- [W3C status messages](https://www.w3.org/WAI/WCAG22/Understanding/status-messages.html?trk=article-ssr-frontend-pulse_little-text-block) and [focus order](https://www.w3.org/WAI/WCAG22/Understanding/focus-order.html) support truthful programmatic status and meaningful navigation. Preserve Close/status recovery where authorized, do not steal focus on late completions, and do not expose old account/profile information after a transition. Widget semantics and emulator tests do not establish spoken TalkBack or complete physical-device accessibility.
