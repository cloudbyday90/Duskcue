# Verified cached Rust qualification

`scripts/testing-memory/run-cached-rust-tests.mjs` executes one exact test from an already compiled library-test executable. It does not invoke Cargo, a compiler, a linker, a shell or a package installer. Compilation remains subject to the separate Cargo/build reserve.

The runner must be a child of the normal memory workflow. It inherits the workflow resource ID and container marker, validates their workspace directory, and keeps the existing parent sampler, serial workflow lock, process-tree ownership and owned-container cleanup. Direct children use `windowsHide`, one Rust test thread, a bounded output buffer and a five-minute deadline. Interrupted or timed-out children are stopped only through the existing PID/name/parent/creation-time revalidation helper. The parent still owns cleanup if the runner is terminated. Node's V8 heap setting does not bound native memory, the Rust process or Docker; the sampler measures the entire owned process tree and system commit.

Before execution, the manifest must match the executable's SHA256, the recorded compile evidence's SHA256, and a complete current inventory/hash snapshot of server source, tests, migration SQL, assets, local Rust dependencies, Cargo manifests/lock and any present Cargo/toolchain configuration. Canonical executable paths must remain in workspace `target/debug/deps`. A removed, added or changed source path refuses execution. The runner lists the exact allowed test, validates the snapshot again, and requires a final result of exactly one passing test. A zero-test or ignored-only result is a failure.

The historical compiled-checkpoint manifest is `.cache/tonight-server-tests/current-lib-test-manifest.json`. It records the passing October 7 Cargo library compilation and four lifecycle cases from `.cache/testing-memory/2026-10-07T17-40-00-887Z-777fae98-e6cf-433e-a236-b8587c633124.jsonl`. Its executable is `target/debug/deps/duskcue-026cb1c87cf24d33.exe`, SHA256 `38b198d0e616df9b3ae9faa8144790ce5b107c8188004dd1c949f86920f8d9b2`; that snapshot covers 329 files. Every recorded source's modification time was earlier than the observed artifact. No automatic manifest-refresh option is exposed: a source change requires a new observed successful compilation and an explicit new snapshot.

The small built-in Node test file verifies unchanged artifacts, source inventory/byte changes, executable/evidence changes, path confinement and exact-test matching without launching Rust, Docker or a compiler. A prepared runner or manifest is not passing runtime evidence.

Implementation was checked against the current official [Node child-process documentation](https://nodejs.org/api/child_process.html) on October 7, 2026 for direct spawn, process completion, stdio and Windows hidden-window behavior.

The exact case passed against the focused default-font derived image on October 7 in 13.34 seconds. Later nullable-profile Stop, owned no-swap helper and fixture refinements changed Rust bytes. A pure validation check confirmed that this manifest now refuses current source before spawning any child; no hash was refreshed to make stale source appear compiled. Retain it as evidence of the earlier checkpoint and record a new snapshot only after an observed successful current compilation. Current source-only helper preparation is not current binary proof.
