# Duskcue agent guidance

Read [CONTEXT.md](CONTEXT.md) at the start of each session for standing development directives. Use [BUILD_ORDER.md](BUILD_ORDER.md) for the implementation sequence and consult the authoritative documents linked from the current phase.

For open feature or domain design decisions, follow [Design review with grill-me](CONTEXT.md#design-review-with-grill-me). The repository-local entry point is [.agents/skills/grill-me/SKILL.md](.agents/skills/grill-me/SKILL.md).

For disk growth and after substantial build/qualification series, use [.agents/skills/duskcue-repository-cleanup/SKILL.md](.agents/skills/duskcue-repository-cleanup/SKILL.md). Maintain owned development artifacts routinely; preserve application data, current reusable artifacts and compact test evidence. Service interruptions and other-project cleanup require applicable authorization.
