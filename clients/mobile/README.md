# Duskcue Mobile

Phase 16a Task 1 creates the Flutter Android/iOS scaffold and dependency baseline.

## Commands

```bash
flutter pub get
flutter analyze
flutter test
flutter build apk --debug
flutter build ios --simulator
```

The current scaffold is an online-client shell. Auth, browsing, playback, foreground SSE, push registration, and quality reporting are implemented by later Phase 16a tasks.
